# Working in this repo

Notes for anyone, human or coding agent, making changes to Hermes.

## What it is

Hermes is an OpenStack audit trail API. OpenStack services emit CADF audit events, a separate pipeline writes them into OpenSearch, and Hermes serves them back per tenant, authenticated against Keystone. Hermes only queries OpenSearch; nothing in this repo writes events to it.

It also owns one small read/write store: per-project dataplane routing config, kept in Postgres (`pkg/routing`) and served on `/v1/projects/{project_id}/dataplane-config`. [ADR 001](docs/adr/001-dataplane-routing.md) and the [read contract](docs/dataplane-config-read-contract.md) describe how a consumer reads that table.

Module: `github.com/sapcc/hermes`. The Go version is whatever `go.mod` says.

## Layout

| Path | What's there |
|---|---|
| `main.go` | Config loading, driver selection, server start |
| `pkg/api` | HTTP handlers, routing, middleware, Prometheus metrics |
| `pkg/hermes` | Filter and list logic between the API and storage |
| `pkg/storage` | `Storage` interface, OpenSearch implementation, `Mock` |
| `pkg/routing` | Dataplane-config store: Postgres implementation and `Mock` |
| `pkg/identity` | Keystone token validation |
| `pkg/policy` | Policy tests |
| `pkg/test` | Test helpers and a permissive test policy |
| `etc/` | Example config (`hermes.conf`, `hermes-mock.conf`) and `policy.json` |
| `docs/` | User API reference, operator guide and config reference, ADRs |

## Build and check

```sh
make                 # build to build/hermes
make check           # static checks + tests with coverage + build
make static-check    # golangci-lint, shellcheck, dependency licenses, license headers, REUSE
make run-typos       # spelling check
make build/cover.out # tests with coverage only
make license-headers # add SPDX headers to new files
```

CI runs `typos` as a separate step, and `make static-check` does not include it. Run both `make static-check` and `make run-typos` before pushing. A typo in a comment, doc or variable name fails CI.

`Makefile`, `.golangci.yaml` and the CI workflows are generated by go-makefile-maker (their headers say so), and so is `REUSE.toml`, from the `reuse` section. Don't edit them by hand; change `Makefile.maker.yaml` and regenerate.

## Running locally

`etc/hermes-mock.conf` selects the mock Keystone and storage drivers and a permissive policy. The routing store defaults to `postgres`, so to run without Postgres, make sure `routing_store_driver = "mock"` is set in its `[hermes]` section.

```sh
make && ./build/hermes -f etc/hermes-mock.conf
```

Drivers are chosen in the `[hermes]` section: `keystone_driver` (`keystone` or `mock`), `storage_driver` (`opensearch` or `mock`), `routing_store_driver` (`postgres` or `mock`; any other value is fatal at startup). See [docs/operators/config.md](docs/operators/config.md) for every key and default.

Environment variables the code reads:

| Variable | Used for |
|---|---|
| `HERMES_DEBUG` | Debug logging |
| `HERMES_OS_USERNAME`, `HERMES_OS_PASSWORD` | OpenSearch basic auth |
| `HERMES_PG_HOSTNAME`, `HERMES_PG_PORT`, `HERMES_PG_USERNAME`, `HERMES_PG_PASSWORD`, `HERMES_PG_DBNAME`, `HERMES_PG_CONNECTION_OPTIONS` | Postgres for the routing store |
| `HERMES_AUDIT_RABBITMQ_QUEUE_NAME` and the other `HERMES_AUDIT_RABBITMQ_*` settings | Where Hermes sends its own CADF events for dataplane-config changes. Unset means events are only logged at debug level |

## API

| Method | Path | Policy rule |
|---|---|---|
| GET | `/`, `/v1/` | none |
| GET | `/v1/events` | `event:list` |
| GET | `/v1/events/download` | `event:list` |
| GET | `/v1/events/{event_id}` | `event:show` |
| GET | `/v1/attributes/{attribute_name}` | `event:list` |
| GET, PUT, DELETE | `/v1/projects/{project_id}/dataplane-config` | `dataplane_config:manage` |
| GET | `/metrics` | none |

Reference: [docs/users/hermez-v1-reference.md](docs/users/hermez-v1-reference.md). Update it in the same PR when you change a response or a parameter.

## Conventions

- **Routing:** every API section implements `httpapi.API` and gets combined with `httpapi.Compose`. There's no hand-built router.
- **JSON responses:** use `ReturnESJSON` (`pkg/api/response.go`), not `respondwith.JSON`. It turns Go's `&` escape back into a literal `&` and sets the `nosniff` and `no-store` headers.
- **Errors:** use `respondwith.ObfuscatedErrorText` for backend/storage failures. The client gets an opaque ID and the details are logged, so OpenSearch or Postgres internals never reach callers. Only 4xx responses about the caller's own input say what went wrong; the handlers write those with `http.Error`.
- **Tenant isolation:** it's per document, not per index. Every query filters on the `tenant_ids` field. `storage.AllTenants` (`"*"`) turns that filter off and is only for admin (`cluster_viewer`) queries. Storage rejects empty tenant IDs and the literal `"unavailable"`.
- **Writes:** the dataplane-config endpoints are the only write path. Besides the policy rule, `authDataplaneConfig` requires the path `project_id` to match the token's project, unless the caller is a cloud admin (`cluster_viewer`). Copy this pattern for any new mutating endpoint.
- **Parameter parsing:** sort, time range, limit and offset parsing in `pkg/api/events.go` is strict and validated. Extend it; don't bypass it.
- **go-bits:** use its helpers: `logg`, `must.Succeed`/`must.Return` at startup, `errext.As` instead of manual type assertions, `osext` for env parsing.
- **Imports:** stdlib, then third party, then `github.com/sapcc/hermes` (goimports enforces this).
- **Licensing:** every source file needs SPDX headers (`make license-headers`). Files that can't carry a header are listed in `Makefile.maker.yaml` under `reuse`.

## Tests

- API tests in `pkg/api/api_test.go` are table-driven: method, path, expected status, expected-response fixture in `pkg/api/fixtures/`.
- Use the mock drivers: `storage.Mock`, `routing.Mock`, and the go-bits mock validator. `pkg/test/policy.json` allows everything.
- Tests that build the API set `prometheus.DefaultRegisterer = prometheus.NewPedanticRegistry()` first, so metric registration doesn't collide between tests. Do the same in new ones.
- `storage.Mock` returns the same static events for every query, ignoring filters, sorting and paging. Test those in the `pkg/api` parsing tests, or against the `httptest` OpenSearch server in `pkg/storage/opensearch_test.go`.
